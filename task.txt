### 🔹 **FIND**

1. Display all students in the collection.
command :- 
    db.user.find()

2. Display only the names and courses of all students.
command :-
    db.students.find({},{name:1,email:1,_id:0})

3. Find all students where the course is **ReactJS**.
command :-
    db.students.find({"course":"ReactJS"})

4. Find all students where the status is **active**.
command:-
    db.students.find({"status":"active"})

5. Display only the names and mentors of all students.
command :-
    db.user.find({},{name:1,mentor:1})

6. Find all students whose mentor is **Pratik Sabale**.
command :- 
    db.students.find({mentor:"Pratik Sabale"})

7. Find all students whose batch code is **B001**.
command :-
    db.students.find({batch:B001})

8. Find all students whose course is **MERN Stack**.
command :-    
    db.students.find({course:"MERN Stack"})

9. Display only the name, email, and course of all students.
command :-
    db.students.find({},{name:1,email:1,course:1})

10. Find all students whose mentor is **Rutvij Joshi** and show only their names.
